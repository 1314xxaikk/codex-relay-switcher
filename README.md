# Codex 中转站切换助手 (codex-relay-switcher)

Windows 上双击就能用的图形小工具：把「切换 Codex 所连 AI 中转站要改的东西」做成问卷式表单，填好点一下按钮，自动帮你改好配置并（可选）重启本地中继，不用手动碰代码或配置文件。

## 它能干什么
- 问卷式界面，从上到下逐题填写
- 可填/选：连接模式、中转站地址、API Key、网络方式、模型
- 模型不用手输：内置近一年主流模型可点选；也可点「获取该站真实模型」自动拉取该站支持的模型并合并进列表
- 方案管理：可存任意多套方案，支持 载入 / 调整 / 复制 / 改名 / 删除
- 一键切换：自动备份 → 改 Codex 配置 → 写 API Key（用户环境变量 + 可选 key.txt）→ 改本地中继并重启 → 输出结果报告
- 一键恢复：切换前都留有备份，可退回上次配置
- 批量试通：把选中的模型逐个真发一条最小请求，能用的留着（不通先问你再删）
- 一键切到最优：自动体检所有方案并切到最快最稳那个
- 导入 / 导出方案（可含或不含 API Key）
- 用量统计：token 估算 + 按参考单价算费用
- 操作日志：时间戳落盘，界面可看/清空/打开文件夹
- 可选托盘常驻：缩到右下角、点 X 最小化（需 pystray）

## 两种连接模式
| 模式 | 说明 |
|---|---|
| 本地中继模式 | 你的请求先走一个本机中继/转发脚本，再转给上游站点。适合需要特殊请求头或代理的站。需要你在 `paths.json` 里指定中继脚本路径。 |
| 直连模式 | Codex 直接连标准 OpenAI 兼容站（新-api / sub2api 等）。 |

网络方式可选「直连 / 走本地代理」，代理地址可自行填写（不写死）。「测连通」会告诉你这个站直连还是走代理才通。

## 怎么启动
1. 双击 `工具本体\启动中转站切换助手.bat`（需要电脑装有 Python 3，带 tkinter）
2. 首次打开会自动把检测到的当前配置存成「方案一」（若检测不到中继则不建）
3. 在「首页」填新站信息 → 「立即连接」或「存为新方案」
4. 改完**重启 Codex 或新开对话**后生效

## 配置与本机适配
所有目标路径和默认代理都是**通用空值**，不写死任何人的机器。在 `工具本体\` 下建一个 `paths.json` 即可按你的机器配置，例如：

```json
{
  "codex_config": "C:\\Users\\你\\ .codex\\config.toml",
  "relay_dir": "C:\\path\\to\\your-relay",
  "relay_py": "C:\\path\\to\\your-relay\\relay.py",
  "key_txt": "C:\\path\\to\\your-relay\\key.txt",
  "pythonw": "C:\\path\\to\\pythonw.exe",
  "proxy_url": "http://127.0.0.1:7890",
  "relay_port": 8123
}
```

若中继脚本缺失，直连模式仍可用；只有「本地中继模式」需要中继相关路径。

## 它改哪些文件（改前都自动备份 `.bak_switcher_时间戳`）
- `~/.codex/config.toml`（模型与连接地址）
- 本地中继脚本（可选）：把常量 `UPSTREAM` / `HEMA_PROXY` / `MODEL_OVERRIDE` 改成方案值
- API Key：用户环境变量 `AGENT_ROUTER_TOKEN`（Codex 配置里的 `env_key` 对应它）；若配置了 `key_txt` 也会写入

> 提示：如果你的 Codex provider 用的是别的 `env_key`，请改自己 Codex 的 `config.toml` 或把 `AGENT_ROUTER_TOKEN` 改成对应的名字（在 `relay_switcher.py` 里改常量即可）。

## 隐私 / 安全
- 一切都在你本机运行；方案与 API Key 存于 `工具本体\_data\`（已在 `.gitignore`，不会上传）
- `paths.json`（含你的机器路径/代理）不会上传
- 切换前自动备份；写 C 盘前界面会再次让你确认
- 只针对 `github.com` 走代理的 git 设置属于个人 `~/.gitconfig`，与本工具无关
